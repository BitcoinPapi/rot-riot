# ROT RIOT

A top-down twin-stick zombie arena shooter. First playable draft, made in
Godot 4 with GDScript. All art is placeholder shapes and all sounds are
generated by code - nothing is taken from any other game.

## Play it in Godot

1. Download **Godot 4** (standard version, not ".NET") from
   <https://godotengine.org/download> - version 4.7 or newer is best.
   It is a single program, no installer needed.
2. Start Godot. In the Project Manager click **Import**, choose the
   `project.godot` file in this folder, then **Import & Edit**.
3. Press **F5** (or the Play button at the top right). The game starts on the
   main menu.

If Godot says the project was made with a different version, accept - it
works on 4.5 and later.

## Controls

|            | Keyboard + mouse        | Gamepad              |
|------------|-------------------------|----------------------|
| Move       | WASD or arrow keys      | Left stick           |
| Aim        | Mouse                   | Right stick          |
| Shoot      | Left mouse button (hold)| Right trigger (hold) |
| Rage       | Space or right click    | LB, LT or X          |
| Pause      | Esc or P                | Start                |
| Fullscreen | F11                     | (Settings menu)      |
| Menus      | Mouse, or arrows + Enter| D-pad / stick, A, B  |

## How it plays

- Zombies come out of the trees in waves that keep getting bigger. Every 5th
  wave brings a boss.
- You start with a pistol. **Crates** drop into the arena with a better
  weapon (shotgun, machine gun, launcher, sledgehammer) that lasts about 20
  seconds. An arrow at the edge of the screen points to crates out of view.
- Kills fill the orange **rage** bar. When it is full, press Space: nearby
  zombies are blasted away and you are much stronger for 8 seconds.
- Zombies drop **coins**. Spend them in **Upgrades** on the main menu
  (damage, fire rate, move speed, max health). Upgrades and coins are saved.

## Tuning the game

Open `scripts/config.gd` in Godot (double-click it in the FileSystem panel).
Every number that matters is there with a comment: player speed, weapon
damage and fire rates, zombie health, wave sizes, shop prices, and all the
"feel" values - screen shake, hit stop, knockback, recoil. Change a number,
press F5, try it.

## Replacing placeholder art and sounds

- Sprite: put a PNG named like the sprite in `assets/sprites/`
  (for example `shambler_0.png`, `player.png`, `boss_0.png`), drawn facing
  right at twice the size listed in `scripts/autoload/art.gd`.
- Sound: put a `.wav` or `.ogg` named like the sound in `assets/sfx/`
  (for example `shotgun.wav`). The names are listed at the top of
  `scripts/autoload/sfx.gd`.

## Exporting builds for friends

One-time setup: in Godot choose **Editor > Manage Export Templates >
Download and Install** (about 1 GB).

Then **Project > Export...** - two presets are already set up:

- **Windows Desktop** - select it, click **Export Project...**, untick
  "Export With Debug", save as `RotRiot.exe`. You get one file. Zip it and
  send it. Windows may show a blue "Windows protected your PC" box the first
  time: click **More info > Run anyway**.
- **macOS** - select it, click **Export Project...**, untick "Export With
  Debug", save as `RotRiot.zip`. Send the zip. Your friend unzips it and gets
  `Rot Riot.app`. Because the app is not signed with a paid Apple developer
  account, macOS blocks it the first time: open it once, then go to
  **System Settings > Privacy & Security**, scroll down and click
  **Open Anyway**. (On older macOS: right-click the app > Open.)
  This works from a Windows PC too - you do not need a Mac to export.

Before changing the macOS preset for a real release, set your own
"Bundle Identifier" in the export dialog (it is `com.rotriot.game` now).

## Automated checks (optional)

From a terminal in this folder, with `godot` on your PATH:

```bash
godot --headless -d --fixed-fps 60 -- --autotest
```

```bash
godot --headless -d --fixed-fps 60 -- --inputtest
```

```bash
godot --headless --fixed-fps 60 -- --bench=250
```

The first plays through the whole game automatically (menus, every weapon,
rage, boss, death, shop, save file), the second checks every control, the
third measures speed with 250 zombies. See `CLAUDE.md` for the design notes.
