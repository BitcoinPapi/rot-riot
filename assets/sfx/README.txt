Sound files in this folder replace the sounds the game generates.

Name the file like the sound (the list is at the top of
scripts/autoload/sfx.gd), for example:
  pistol.ogg  shotgun.ogg  machinegun.ogg  launcher.ogg  explosion.ogg
  sledge_swing.ogg  zombie_die.ogg  coin.ogg        (.wav and .mp3 work too)

Several recordings of one sound: name them  zombie_hit_1.ogg, zombie_hit_2.ogg,
zombie_hit_3.ogg ...  and the game picks a different one each time.

To get a generated sound back, delete its files here (and the ".import"
file next to each).
