Drop .wav or .ogg files here to replace the generated sounds.

Name the file like the sound (see the list at the top of
scripts/autoload/sfx.gd), for example:
  pistol.wav  shotgun.wav  machinegun.wav  launcher.wav  explosion.wav
  sledge_swing.wav  sledge_hit.wav  zombie_hit.wav  zombie_die.wav  coin.wav
